# Changelog

## 0.1.0

- Added webcam head-pose estimation and an OpenCV debug preview.
- Added calibration, an attention state machine, and repeating audio alerts.
- Added manual arm and disarm controls, a global hotkey, and automatic disarm.
- Updated Intel Mac setup to use Python 3.12 and prebuilt wheels.
- Added macOS menu bar mode, sound previews, sensitivity presets, and `run.sh`.
- Added the loopback WebSocket server and unpacked Manifest V3 extension for generation-driven arming.
- Added calibration retries, local session stats, launch at login, and Gemini alongside Claude and ChatGPT.
